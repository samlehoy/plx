# Perubahan singkat — plx landing (frontend sudah jadi)

Daftar perubahan kecil yang harus diterapkan ke landing page yang sudah ada. Fokus pada copy dan positioning — jangan ubah layout, palet, atau komponen yang tidak disebut di sini.

## Arah produk

1. **Eyebrow hero** — ganti `SPOTIFY → DEEZER` menjadi `SPOTIFY ⇄ DEEZER`.
2. **Headline accent** — ganti `Skip the login.` menjadi `No dev account.`.
3. **Lede** — pertegas jadi soal "browser sessions, not API keys" dan "no Developer account". Arah yang benar-benar berjalan = Spotify → Deezer. Arah Deezer → Spotify **belum ship**, hanya boleh disebut "reverse soon" / "planned".

## Evidence rules

4. Reverse direction (Deezer → Spotify) hanya boleh ditampilkan sebagai "reverse soon" / "planned", **jangan** ditampilkan sebagai fitur yang sudah ship.

## Jangan ubah

- Struktur tujuh section, palet achromatic + satu accent, tipografi (Archivo / IBM Plex Mono).
- Komponen occlusion weave, counter-travel record stage, match-tier picker.
- Spec table dan klaim angka apa pun — tetap sesuai yang sudah ada.
